What is OICD ?
- OpenID Connect (OIDC) -> Identity layer built on top of OAuth2.
- User authentication to an IdP (RedHat SSO, Keyclock etc).
- IdP issues a JWT ID token describing who the user is, and where the user/claim belongs.
- Application (Consider k8s distributor like openshift) verify and "trust that token" instead of asking for password.

JWT structure?
 - JWT has three parts:-
   1-# Header 
       - Token type and signing algorithm.
	   - Example:-
	      JSON -> {"alg":"RS256", "typ":"JWT"}
  
  2-# Payload ( claims)
      - key/value information about user.
      - Example:
         JSON/YAML 
        {
		 "sub": "a123-uuid",
		 "preferred_username: "john",
		 "email": "john@example.com",
		 "name": "John Xyz",
		 "groups": ["sre_grp", "devops_grp"]
		 }
		 
  3-# Signature   
      - Cryptographic signature using IdP's private key.
	  - OPenshift uses IdP's public key/ CA to verify it wasn't tampered with anything.
